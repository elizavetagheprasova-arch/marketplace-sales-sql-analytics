## Профессиональная основа
Руководитель филиала, 10.10.2022–14.09.2026, команда 11 сотрудников. Практический контекст: закупки, склад, товарные движения, первичные документы, остатки, расходы, кассовые операции, взаиморасчёты и управленческая отчётность.

1С:УНФ, 1С:Бухгалтерия и 1С:ERP — функциональный пользовательский уровень. SQL/Python — самостоятельные портфолио-проекты на синтетических данных. Не заявляются программирование 1С, разработка конфигураций, коммерческие BI-внедрения или не подтверждённые бизнес-результаты.

Синтетические данные явно маркируются. Оценочные исторические результаты не представлены как подтверждённые финансовые KPI. 1С указана только на функциональном уровне. Логическая ERD — демонстрационная модель, не reverse engineering реальной конфигурации 1С.

# Аналитика продаж маркетплейса | SQL Portfolio

**Учебный аналитический проект на PostgreSQL и Supabase**: анализ выручки, расчётной прибыли, маржинальности, динамики продаж и эффективности товарных категорий.

## Задача

На основе учебных данных маркетплейса получить показатели, полезные для операционных и коммерческих решений:

- оценить продажи и расчётную прибыль;
- сравнить товары и категории по доходности;
- увидеть динамику по месяцам;
- выявить товары с относительно низкой маржинальностью;
- представить результаты в удобном интерактивном отчёте.

## Что есть в дашборде

- Переключение между всем периодом и отдельными месяцами.
- KPI: выручка, прибыль, маржа, количество проданных товаров.
- График выручки и прибыли по месяцам.
- Рейтинг товаров по прибыли.
- Таблицы прибыльности товаров и категорий.

Дашборд — статический HTML с JavaScript. Данные выгружены из Supabase и встроены в страницу; **прямого подключения к базе при открытии сайта нет**.

## SQL-примеры

В файле [`sql/analysis_examples.sql`](sql/analysis_examples.sql) приведены запросы для анализа продаж, прибыли, маржинальности, ABC-групп и качества данных.

**Важно:** файл содержит иллюстративные SQL-примеры с описанной демонстрационной схемой. Для запуска в исходном проекте Supabase названия столбцов необходимо сверить с реальными таблицами. Источник показателей дашборда — выгрузка из `public.vw_sales_profitability`.

## Методика

```text
Выручка = сумма продаж
Расчётная прибыль = выручка − закупочная стоимость − комиссия − доставка
Маржа, % = расчётная прибыль / выручка × 100
```

Расчётная прибыль **не является чистой прибылью бизнеса**: не учтены налоги, возвраты, реклама, хранение, зарплаты и другие накладные расходы. Записи о продажах не обязательно равны уникальным заказам.

## Выводы

- Категория **«Одежда»** формирует наибольшую часть расчётной прибыли.
- **Кроссовки** имеют сравнительно низкую маржу среди представленных товаров (около **45,7%**); для управленческого решения стоит отдельно проверить закупочную цену, комиссию и доставку.
- Помесячный фильтр позволяет быстро сопоставлять результаты и находить периоды для дальнейшего анализа.

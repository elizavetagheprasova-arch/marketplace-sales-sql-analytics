Кейс 5. Требования и бэклог: Jira / Confluence

Учебный системно-аналитический проект

Задача

Показать, как формализовать задачу автоматизации складского учёта для команды разработки.

Что сделано

BRD и SRS; User Stories; критерии приёмки; Epic, Story, Task и Sub-task; Definition of Done; пример контракта резервирования.

Результат

Подготовлены учебные PDF-требования и Excel-бэклог; измеренного коммерческого эффекта нет.

Ограничения данных

Excel-бэклог не является выгрузкой из реальной Jira; структура Confluence учебная; API приведён как пример.
